# AbakasAwesomeTuner

An all-in-one musical toolbox with everything you need when practicing!

## Current features

- Tuner with simple frequency playback
- Controls for switching semitones

## Planned features

- Extra pitch displays for different instrument groups (e.g. Bb instruments, or F instruments)
- Octave switcher
- Piano diagram to indicate what note you're on
- Fingering charts
- Metronome
- Volume controls
